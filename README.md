# 🛍️ MarketSegment — Unsupervised Customer RFM Clustering

> A customer segmentation analysis pipeline utilizing K-Means clustering and RFM (Recency, Frequency, Monetary) modeling to discover actionable behavioral cohorts for targeted marketing and customer retention.

## 🚀 Features

- **RFM Metric Engineering** — Extracts Recency, Frequency, and Monetary scores from transaction records to quantify customer lifetime value.
- **Optimal K Determination** — Uses the Elbow Method (Inertia) and Silhouette Score analysis to determine optimal cluster counts.
- **Actionable Cohorts** — Segments customers into high-value VIPs, regular buyers, at-risk churners, and dormant shoppers.
- **Visual Exploratory Analysis** — Generates clear 2D and 3D cluster visualizations showing customer distribution in feature space.
